# Petrel Davranış Kuralları

[English](CODE_OF_CONDUCT.md) · [Türkçe](CODE_OF_CONDUCT_TR.md)

## Topluluk kuralları

Herkese saygılı davranın. Yapıcı geri bildirim verin, eleştirilerinizi yapılan işe odaklayın ve farklı geçmişlere ve deneyim düzeylerine sahip kişilerin katılımına alan açın.

Taciz, tehdit, kişisel saldırı, ayrımcı ifadeler ve başkasının özel bilgilerini izinsiz paylaşmak kabul edilemez.

Bu kurallar Petrel'in GitHub issue, pull request ve tartışma alanlarında, ayrıca projenin yönettiği diğer alanlarda geçerlidir.

## Bildirim ve uygulama

İhlalleri, GitHub profilinde yer alan iletişim bilgilerini kullanarak bir proje yöneticisine özel olarak bildirin. Mümkünse ilgili konuşmanın bağlantısını ekleyin. GitHub kurallarını ihlal eden içerikler için GitHub'ın bildirim araçlarını da kullanabilirsiniz.

Proje yöneticileri, bildirimleri yalnızca inceleme ve çözüm için gerektiği ölçüde paylaşır. İhlalin ciddiyetine ve tekrarlanma durumuna göre içeriği kaldırabilir, uyarı verebilir veya katılımı kısıtlayabilirler.
