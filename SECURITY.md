# Petrel Security Policy

[English](SECURITY.md) · [Türkçe](SECURITY_TR.md)

## Reporting a vulnerability

Use [Report a vulnerability](https://github.com/sezgynus/Petrel/security/advisories/new) to send a private report to the maintainers if GitHub offers that option. If private reporting is unavailable, open an issue asking for a private contact method. Keep the vulnerability details out of the public issue.

Include the affected Petrel version or commit, relevant environment details, the affected component, the potential impact, and enough information for maintainers to investigate. Remove credentials, tokens, and personal data from any attachments. If you know whether the issue affects the latest version on `master`, include that information.

Please coordinate public disclosure with the maintainers so they have time to investigate and prepare a fix.
